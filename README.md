# 👟 F1rstep Shoes

A modern e-commerce website built for a footwear and fashion brand.

## 🌐 Live Website

https://f1rstepshoes.netlify.app/

## 📌 About

F1rstep Shoes is an e-commerce website designed to showcase and sell footwear and fashion products online.

The website includes different product categories, product collections, search functionality, a shopping cart, and a WhatsApp-based checkout system.

It also includes an admin panel for managing products, including product details, pricing, categories, stock, sizes, tags, and images.

## ✨ Features

* 👟 Product categories
* 🔍 Product search
* 🛍️ Shopping cart
* 📦 Product collections
* 💬 WhatsApp checkout
* ⚙️ Admin product management
* 📱 Responsive web design
* 🚀 Deployed using Netlify

## 🛠️ Technologies

* HTML
* CSS
* JavaScript
