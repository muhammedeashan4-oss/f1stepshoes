# F1rstep Shoes

A responsive e-commerce website created for F1rstep Shoes.

## Live Website

https://f1rstepshoes.netlify.app/

##Features

* Product browsing
* Product categories
* Search functionality
* Shopping cart
* Product collections
* WhatsApp-based checkout
* Responsive web design

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Overview

This project was developed as a web development project to create an online shopping experience for a footwear and fashion brand. I worked on the website structure, design, functionality and user experience.
